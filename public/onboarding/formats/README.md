# Ejemplos de formato de Sandy

Miniaturas ilustrativas generadas con la herramienta integrada de imágenes de Codex. No son archivos de modelos ni capturas de avatares ejecutándose.

- `sandy-pngtuber.png`: ilustración 2D plana con contorno marcado y sombreado sencillo.
- `sandy-live2d.png`: ilustración 2D detallada con pelo por capas y sombreado suave.
- `sandy-vrm.png`: representación anime con volumen, materiales y sombreado tridimensional.

Referencia de identidad: `public/avatars/sandy/sandy_idle.png`. Fondo transparente en los tres archivos. Los originales se conservan sin cambios.

## Prompts utilizados

Base común: “Create one clean square example thumbnail for Sandy Studio onboarding, using the supplied image ONLY as the identity reference. Preserve Sandy exactly: long black hair, one red streak on the viewer's left, turquoise/blue streak on the viewer's right, green four-leaf-clover hairpin on viewer's right, blue eye viewer's left and red eye viewer's right, white blouse, deep magenta bow and black dress with purple piping. Friendly composed smile. Bust portrait centered with some empty margin around hair, no cropping of top of hair, consistent front/very slight three-quarter framing, no lettering, no logos, no interface, no border, no watermark. This is a still illustrative example, not a UI mockup. Transparent background.”

PNGTuber: “Style: crisp flat 2D anime PNGTuber sprite. Expressive slightly chibi proportions, strong tidy outlines, simple two-tone cel shading and a static frontal cutout silhouette. Make it distinctly flat and drawn.”

Live2D: “Style: polished 2D Live2D avatar illustration. Normal anime proportions, delicate precise linework, detailed layered hair strands and soft painted cel shading. Slight head tilt, natural lively face. Remain visibly a 2D illustration, distinct from a flat chibi sprite and from a 3D render.”

VRM: “Style: clearly three-dimensional VRM anime avatar render, normal anime proportions. Sculpted hair locks, visibly modeled blouse and bow, soft studio lighting with material shading and subtle 3D depth. Slight three-quarter face angle. Preserve the anime identity; no photorealism, no clay toy, no chibi.”
